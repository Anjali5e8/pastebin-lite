# Pastebin-Lite

A lightweight text-sharing service built with Next.js and PostgreSQL. This application allows users to create pastes with optional expiration times (TTL) and maximum view limits.

## Project Description
This is a "Pastebin" clone designed to handle arbitrary text pastes with specific constraints. Once a paste reaches its expiration time or its maximum view count, it becomes immediately unavailable (404).
